座りっぱなしの足に ふくらはぎを動かす足首回しとかかと上げ

座りっぱなしで足が重だるい日に。ふくらはぎを動かして足の血のめぐりを助ける、足首回しとかかと上げのやり方を紹介します。

この記事のポイント
  1. ふくらはぎは血液を心臓へ戻す手助け役
  2. 座ったまま足首を大きくゆっくり動かす
  3. 片足だけの腫れや急なむくみは受診を

ふくらはぎは、足の血のめぐりを助けている

心臓から送り出された血液は、足先まで届いたあと、また心臓へ戻っていきます。足から心臓へ戻るには、重力に逆らって上がらなければなりません。このとき手助けをしているのが、ふくらはぎの筋肉です。

ふくらはぎの筋肉が縮んだりゆるんだりすると、その中を通る血管が押され、血液が上へ送られます。このポンプのようなはたらきから、ふくらはぎは「第二の心臓」と呼ばれることがあります。

長い時間座りっぱなしでいると、ふくらはぎはほとんど動きません。夕方に足が重だるく感じることもあります。こまめに足首を動かして、ふくらはぎを使ってあげることが大切です。

年齢を重ねると、ふくらはぎの筋肉は細くなりやすく、歩く量が減るとさらに使われなくなります。ふだん歩くことに加えて、座っている時間にも足を動かす習慣をつけておくと安心です。

座ったままできる足首の曲げ伸ばしと足首回し

テレビを見ながら、デスクワークの合間に、座ったままでできます。椅子は、足の裏が床にしっかりつく高さのものを選んでください。

  1. 椅子に深く腰かけ、背すじを軽く伸ばします。
  2. 片足を少し前に出し、かかとを床につけたまま、つま先をゆっくり上げて下ろします。これを10回ほどくり返します。
  3. 次に、足を床から少し浮かせ、足首で大きく円を描くように回します。外回し、内回しを5回ずつ行います。
  4. 反対の足も同じように行います。

足首を動かすと、ふくらはぎの筋肉がのびたり縮んだりするのを感じられるはずです。ゆっくり、大きく動かすのがポイントです。足の指をグーとパーに動かすのもあわせて行うと、足裏から足首まわりまでほぐれる感じがあります。足を組んで座るくせがある方は、両足を床につけて座る時間もつくってみてください。

立って行うかかと上げ

ふらつきのない方は、立って行うかかと上げもおすすめです。

  1. 机や椅子の背に両手を軽く添えて立ちます。足は腰幅に開きます。
  2. ゆっくりかかとを上げて、つま先立ちになります。
  3. 上げたところで一呼吸おき、ゆっくりかかとを下ろします。
  4. これを10回ほどくり返します。

立つのが不安な方は、座ったままかかとを上げ下げするだけでも大丈夫です。慣れてきたら、かかとを下ろすときにいつもより時間をかけてみてください。ふくらはぎの筋肉をしっかり使うことができます。

安全のため、次の点を守ってください。

  • 必ずつかまる場所のある所で行う。
  • ふくらはぎがつりそうになったり、痛みが出たりしたら中止する。
  • 反動をつけず、ゆっくり行う。

1時間に一度くらいを目安に、座りっぱなしの時間を区切るつもりで取り入れてみてください。

理学療法士のひとこと

リハビリの現場では、ベッドで過ごす時間が長い方に、足首を動かす運動をよくお伝えしていました。足首の曲げ伸ばしは場所を選ばず、体への負担も少ない動きです。長時間の乗り物での移動中にもおすすめです。ときどき立ち上がって、部屋の中を少し歩くのもよい方法です。

ただし、足のむくみの陰に病気が隠れていることもあります。むくみが急にひどくなった、片足だけが腫れて痛む、赤くなって熱を持っている、息苦しさを伴うといった場合は、体操で様子を見ずに、すぐに医療機関を受診してください。
