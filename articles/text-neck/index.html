スマホを見るとき首が前に出ていませんか？首にやさしい姿勢

スマホをのぞきこむと、頭が前に出て首の後ろの筋肉ががんばり続けます。持ち方の工夫と簡単な体操を紹介します。

この記事のポイント
  1. 頭が前に出ると首の後ろが疲れる
  2. スマホを目の高さに、ひじを支える
  3. 見たあとは「あご引き」で首を戻す

電車の中、ソファの上、寝る前の布団の中。スマホを見ている時間は、思っている以上に長いものです。そのとき、首はどんな形になっているでしょうか。今回は、スマホを見るときの首の姿勢について、理学療法士の目線でお話しします。

頭は思っているより重い

頭は、体の中でもかなり重さのある部分です。まっすぐ立っているときは、その重さを背骨が真下から支えてくれます。ところが、スマホをのぞきこむように頭が前に出ると、首の後ろの筋肉が、頭が前に落ちないよう引っぱり続けなければなりません。

前に出た頭を支え続けると、首から肩、背中にかけての筋肉がこわばりやすくなります。リハビリの現場でも、首や肩のつらさを訴える方の多くが、頭が肩より前に出た姿勢をしていました。

横から見たとき、耳の穴が肩の真上あたりにあるのが、首に負担の少ない位置の目安です。一度、家族に横から見てもらったり、鏡の前でスマホを見るふりをしてみたりしてください。思っていたより頭が前に出ていて、驚く方も多いと思います。自分のくせに気づくことが、最初の一歩です。

また、頭が前に出ると背中も丸くなりやすく、肩が内側に入ります。首だけでなく、肩や背中までつながって疲れやすくなるのはそのためです。

スマホを見るときの3つの工夫

  1. スマホを目の高さに近づける：画面を下に置いて見下ろすのではなく、スマホのほうを持ち上げます。
  2. ひじを支える：腕を上げ続けると疲れます。反対の手でひじを支えたり、テーブルにひじをついたり、膝にクッションをのせたりすると、ラクに目の高さを保てます。
  3. 目線だけを下げる：少し下を見るときは、首ごと曲げるのではなく、目だけを下に向けるつもりで見ます。

寝転がって見る場合、うつぶせでひじをつく姿勢は首が反りやすく、負担がかかりがちです。仰向けで見るなら、手が疲れたら休むことを忘れずに。

首をリセットする「あご引き」

画面を見たあとに、首の位置を戻す簡単な体操です。

  1. 椅子に座り、背すじを軽く伸ばします。
  2. 目線はまっすぐ前のまま、あごを後ろにすっと引きます。二重あごをつくるようなイメージです。
  3. 首の後ろが少し伸びるのを感じたら、3秒ほどその位置を保ちます。
  4. 力を抜いて元に戻します。これを5回ほど繰り返します。

うなずくように下を向くのではなく、頭を水平に後ろへ引くのがポイントです。痛みやしびれ、めまいが出たら、すぐに中止してください。

もうひとつ大切なのは、見る時間を区切ることです。動画を1本見終わったら、いったん顔を上げて遠くを見る。それだけでも、首が同じ形で固まり続けるのを避けられます。

理学療法士のひとこと

「姿勢を正しく」と言われても、ずっと同じ姿勢でいると、実はどんな姿勢でも疲れます。大事なのは、よい姿勢をキープすることより、こまめに姿勢を変えることです。スマホを置いたら首を軽く動かす。それを合図にしてみてください。

ご家族がスマホを使っている姿を見て気になったら、「ちょっと持ち上げてみたら？」と声をかけるのも、よいきっかけになります。文字が小さくて画面に顔を近づけてしまう場合は、文字の大きさを設定で大きくするのもひとつの方法です。

手のしびれや、首の痛みが長く続くときは、無理をせず整形外科で診てもらいましょう。
